# LzyDownloader v1.2.32

This release improves external-tool installation, Windows deployment, download
progress, and release reliability.

## Highlights

- External Tools now consistently recommends app-local installs where
  appropriate, installs Deno without changing `PATH`, and preserves selected
  standalone FFmpeg/FFprobe overrides across restart.
- Added exact Windows WinGet discovery and safer package-manager and standalone
  binary update handling.
- Active Downloads now uses one focused progress bar per row, while Discord
  webhook progress remains aggregate across video/audio handoff.
- Improved external-tool timeout and version diagnostics, including persistent
  prompts for manually managed yt-dlp updates.
- Hardened Windows Qt deployment and headless test configuration, including
  reliable Qt plugin/runtime deployment and debug configure recovery.
- Clarified the CI-first release workflow so tagged GitHub Actions builds are
  the normal packaging path; local release builds are optional diagnostics.
- Refreshed regression coverage for binary paths, WinGet discovery, compact
  active-download rows, and external-tool layout sizing.
- Refreshed yt-dlp and gallery-dl extractor metadata for the release.
