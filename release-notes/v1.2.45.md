# LzyDownloader v1.2.45

This patch release fixes audio downloads that could remain in the temporary
directory after yt-dlp had completed the media transfer.

- Skip redundant FFmpeg metadata rewrites when yt-dlp has already embedded
  artwork and the tracked thumbnail sidecar is no longer available.
- Allow valid audio files to proceed directly to finalization when no metadata
  rewrite is still required.
- Add regression coverage for audio jobs with a missing thumbnail sidecar.

Release assets:

- Windows installer: `LzyDownloader-Setup-1.2.45.exe`
- Linux AppImage: `LzyDownloader-1.2.45-x86_64.AppImage`
- Intel macOS DMG: `LzyDownloader-1.2.45-macos-x86_64.dmg`
- Apple Silicon DMG: `LzyDownloader-1.2.45-macos-arm64.dmg`
