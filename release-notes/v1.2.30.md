# LzyDownloader v1.2.30

This release improves cross-platform packaging, updater reliability, and release validation.

## Highlights

- Added Intel and Apple Silicon macOS app bundles and architecture-labelled DMGs.
- Improved macOS updater asset matching and Finder-based DMG installation handoff.
- Hardened Linux AppImage packaging for static and dynamic Qt builds.
- Added manual build-only release workflow validation while keeping publication tag-only.
- Made binary resolution platform-neutral in command previews and format probing.
- Preserved resumable queue state and stopped helper processes before application updates.

## Assets

- Windows installer: `LzyDownloader-Setup-1.2.30.exe`
- Linux AppImage: `LzyDownloader-1.2.30-x86_64.AppImage`
- Intel macOS DMG: `LzyDownloader-1.2.30-macos-x86_64.dmg`
- Apple Silicon macOS DMG: `LzyDownloader-1.2.30-macos-arm64.dmg`
