# LzyDownloader v1.2.42

This patch release improves multi-instance download coordination, thumbnail
reliability, and browser-companion recovery.

- Enforces the configured `max_threads` limit across concurrent GUI and
  Discord/server/headless/background processes.
- Restores Qt JPEG and PNG image plugins needed for Active Downloads and
  Download History thumbnails in Debug and deployed builds.
- Improves Active Downloads row visibility and keeps disabled toolbar icons
  recognizable in light and dark themes.
- Adds bounded browser-cookie validation and cleanup coverage for the native
  messaging companion.
- Refreshes the bundled yt-dlp and gallery-dl extractor metadata.

Release assets:

- Windows installer: `LzyDownloader-Setup-1.2.42.exe`
- Linux AppImage: `LzyDownloader-1.2.42-x86_64.AppImage`
- Intel macOS DMG: `LzyDownloader-1.2.42-macos-x86_64.dmg`
- Apple Silicon macOS DMG: `LzyDownloader-1.2.42-macos-arm64.dmg`
