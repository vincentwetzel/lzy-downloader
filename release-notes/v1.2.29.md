# LzyDownloader v1.2.29

This release improves recovery, diagnostics, updater reliability, and release packaging.

## Highlights

- Added bounded aria2c recovery with a native yt-dlp fallback when transient failures or missing temporary media output prevent completion, while preserving resumable partial files.
- Restricted low-quality warnings to video downloads, preserved audio-oriented progress for audio extraction, and added the downloaded title plus a clickable source URL when available.
- Improved yt-dlp diagnostics for incomplete media, missing fragments, invalid media input, FFmpeg failures, and recoverable warnings.
- Hardened headless end-to-end test shutdown and made Windows diagnostics safe for console output.
- Application updates now save resumable queue state and stop downloader/helper process trees before installation; silent Windows updates relaunch the freshly installed application.
- Reorganized the footer status layout so counters and current speed stay together while the exit-after-downloads control remains rightmost.
- Improved Linux AppImage packaging by using the vcpkg Qt installation that built the application, including QtSql/SQLite plugin deployment.
- Added release workflow validation improvements, including NSIS installation, required Linux Qt/XCB prerequisites, prerelease yt-dlp validation, manual build-only dispatches, and safer tag-matched release-note handling.

## Release assets

- Windows installer: `LzyDownloader-Setup-1.2.29.exe`
- Linux AppImage: `LzyDownloader-1.2.29-x86_64.AppImage`
