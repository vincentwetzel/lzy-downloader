# LzyDownloader v1.2.33

This release improves non-interactive operation, startup binary updates, and
multi-stream progress stability.

## Highlights

- WinGet-managed Deno updates can fall back to the official stable installer
  when the WinGet catalog lags upstream, with resilient Windows download
  handling and cleaner command diagnostics.
- Startup outdated-binary prompts now offer **Update Now** for every detected
  binary and reuse the External Tools update implementation.
- `--background` now follows the non-interactive server/headless/API path,
  exposing failures through bridge/webhook diagnostics instead of modal dialogs.
- Active Downloads progress now prefers aggregate multi-stream progress and
  avoids backward jumps during video/audio handoff.
- Refreshed the bundled yt-dlp extractor metadata, including the current
  Nitter domain data.
