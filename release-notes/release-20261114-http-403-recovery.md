# LzyDownloader 1.2.61

**More reliable transfers:** If aria2c receives an HTTP 403 response, LzyDownloader
retries once with a fresh media request. If the request is still denied, it
falls back to yt-dlp's native downloader.

The bundled yt-dlp and gallery-dl extractor catalogs are refreshed for this
release.
