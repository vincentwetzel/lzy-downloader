# LzyDownloader v1.2.34

This release substantially reduces Windows and Linux release-build time by
using prebuilt Qt SDKs and packaging only the application target.

## Highlights

- Windows and Linux CI now use the pinned prebuilt Qt 6.10.2 SDK instead of
  compiling Qt through vcpkg.
- Release builds compile the application with explicit host parallelism and
  skip separate test executables during packaging.
- Linux AppImage deployment uses the same Qt SDK that built the application,
  including the QtSql SQLite plugin.

## Assets

- Windows installer: `LzyDownloader-Setup-1.2.34.exe`
- Linux AppImage: `LzyDownloader-1.2.34-x86_64.AppImage`
- Intel macOS DMG: `LzyDownloader-1.2.34-macos-x86_64.dmg`
- Apple Silicon macOS DMG: `LzyDownloader-1.2.34-macos-arm64.dmg`
