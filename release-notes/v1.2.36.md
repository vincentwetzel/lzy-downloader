# LzyDownloader v1.2.36

This maintenance release fixes the Ubuntu GitHub Actions release job after the
v1.2.35 CI reliability update.

## Highlights

- Uses Qt's current `linux_gcc_64` architecture name for the Linux prebuilt SDK.
- Keeps the optimized prebuilt-Qt release pipeline for Windows, Linux, and macOS.

## Assets

- Windows installer: `LzyDownloader-Setup-1.2.36.exe`
- Linux AppImage: `LzyDownloader-1.2.36-x86_64.AppImage`
- Intel macOS DMG: `LzyDownloader-1.2.36-macos-x86_64.dmg`
- Apple Silicon macOS DMG: `LzyDownloader-1.2.36-macos-arm64.dmg`
