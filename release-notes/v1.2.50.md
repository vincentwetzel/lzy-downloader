# LzyDownloader v1.2.50

This release improves coordinator and playlist-probe reliability, tightens
progress parsing and history thumbnail updates, and makes headless test runs
more deterministic.

- Retry transient local-socket startup races and acknowledge accepted
  coordinator commands reliably.
- Probe explicit playlist-shaped video URLs in `Ask` mode while preserving
  ordinary URL fallback behavior.
- Require valid media-size tokens when parsing native completion and transfer
  output.
- Prevent delayed thumbnail reads from replacing newer history thumbnails.
- Add `--no-build`, support valid Visual Studio configure caches, and run Qt
  tests serially for deterministic shared runtime state.
- Refresh the yt-dlp extractor catalog.

Release assets:

- Windows installer: `LzyDownloader-Setup-1.2.50.exe`
- Linux AppImage: `LzyDownloader-1.2.50-x86_64.AppImage`
- Intel macOS DMG: `LzyDownloader-1.2.50-macos-x86_64.dmg`
- Apple Silicon DMG: `LzyDownloader-1.2.50-macos-arm64.dmg`
