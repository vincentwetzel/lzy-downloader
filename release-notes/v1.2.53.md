# LzyDownloader 1.2.53

This release improves download recovery and makes long FFmpeg post-processing
easier to diagnose.

- **Aria2c EOF recovery:** Downloads retry once with yt-dlp's native downloader
  when aria2c loses the remote connection, while unrelated failures remain
  terminal and media partials are preserved.
- **Post-processing diagnostics:** FFmpeg stage timing, progress, descendant
  resource snapshots, and event-loop delay warnings help identify responsiveness
  problems during merges and cuts.
- **Extractor catalogs:** Refresh the bundled yt-dlp and gallery-dl extractor
  catalogs.

Downloads:

- Windows installer: `LzyDownloader-Setup-1.2.53.exe`
- Linux AppImage: `LzyDownloader-1.2.53-x86_64.AppImage`
- macOS Intel DMG: `LzyDownloader-1.2.53-macos-x86_64.dmg`
- macOS Apple Silicon DMG: `LzyDownloader-1.2.53-macos-arm64.dmg`

SHA-256 checksum manifests are published alongside the platform assets.
