# LzyDownloader v1.2.38

This maintenance release completes the Linux AppImage packaging fix.

## Highlights

- Excludes unused Qt SQL drivers from linuxdeploy's directory scan while
  retaining the SQLite driver required by LzyDownloader.
- Preserves Qt SDK caching, Linux ccache, and Ninja build optimizations.

## Assets

- Windows installer: `LzyDownloader-Setup-1.2.38.exe`
- Linux AppImage: `LzyDownloader-1.2.38-x86_64.AppImage`
- Intel macOS DMG: `LzyDownloader-1.2.38-macos-x86_64.dmg`
- Apple Silicon macOS DMG: `LzyDownloader-1.2.38-macos-arm64.dmg`
