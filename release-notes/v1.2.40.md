# LzyDownloader v1.2.40

This patch release improves startup recovery and external-tool update handling.

- Defers binary update actions and the required-tools checklist until the application update decision is resolved.
- Completes startup checks when yt-dlp is missing or its version probe fails, allowing the **Set Up Required Tools** checklist to appear.
- Keeps bundled extractor metadata initialization independent from external binary update results.
