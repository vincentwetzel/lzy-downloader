# LzyDownloader 1.2.64

**More control over download speed:** Choose shared 128 KB/s or 256 KB/s rate
limits. When a proxy tunnel disconnects, LzyDownloader preserves the HTTP
error details and can retry once after yt-dlp exhausts its retries. Stale
metadata sidecars are cleared while media partials remain available to resume.

Progress labels now show combined video and audio status for active
livestreams using separate streams, and the current video or audio stage for
ordinary separate-format downloads.

The bundled yt-dlp and gallery-dl extractor catalogs are refreshed for this
release.

[View the latest release and installers](https://github.com/vincentwetzel/lzy-downloader/releases/latest)

SHA-256 checksum manifests are published alongside the platform assets.
