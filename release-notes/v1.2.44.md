# LzyDownloader v1.2.44

This release improves persistence and shutdown reliability, playlist handling,
transfer progress recovery, and cross-platform release validation.

- Queue and history saves now use coalescing background writers, while orderly
  shutdown flushes the latest queue state and archive writes stay off the GUI
  thread.
- Prevents queued workers from starting during shutdown and preserves playlist
  identity and filename prefixes through probe fallback and resume recovery.
- Moves downloader work, thumbnail and temporary-file checks off the GUI thread,
  coalesces row progress, and improves progress-size recovery from owned partial
  files.
- Adds playlist-policy regression coverage, safer shared settings access, and
  more reliable Windows test deployment.
- Centralizes the full headless release test gate and refreshes bundled yt-dlp
  extractor metadata.

Release assets:

- Windows installer: `LzyDownloader-Setup-1.2.44.exe`
- Linux AppImage: `LzyDownloader-1.2.44-x86_64.AppImage`
- Intel macOS DMG: `LzyDownloader-1.2.44-macos-x86_64.dmg`
- Apple Silicon macOS DMG: `LzyDownloader-1.2.44-macos-arm64.dmg`
