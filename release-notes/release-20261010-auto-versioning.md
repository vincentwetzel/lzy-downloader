# LzyDownloader 1.2.56.65

This release introduces four-part app versions. GitHub Actions uses its run
number for each release, and existing three-part installations can update to
the new version through the in-app updater.

Also included:

- Expanded FFmpeg and headless lifecycle diagnostics.
- More reliable cross-process worker admission when app-data storage is not
  writable.
- Refreshed yt-dlp and gallery-dl extractor catalogs.
