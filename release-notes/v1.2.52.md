# LzyDownloader 1.2.52

This release makes stopping downloads safer and improves day-to-day reliability.

- **Resumable stopping:** The active-download action is now **Stop** and keeps
  partial files available for resuming. Removing temporary files remains an
  explicit cleanup action.
- **Safer completion handling:** Completion processing remains valid even when
  UI callbacks remove or replace an active download during finalization.
- **Cleaner dialogs:** Dialog-style windows no longer show a minimize button.
- **Extractor updates:** Refresh the bundled yt-dlp and gallery-dl extractor
  catalogs, including the current Nitter domain.

Downloads:

- Windows installer: `LzyDownloader-Setup-1.2.52.exe`
- Linux AppImage: `LzyDownloader-1.2.52-x86_64.AppImage`
- macOS Intel DMG: `LzyDownloader-1.2.52-macos-x86_64.dmg`
- macOS Apple Silicon DMG: `LzyDownloader-1.2.52-macos-arm64.dmg`

SHA-256 checksum manifests are published alongside the platform assets.
