# LzyDownloader 1.2.43

This release improves setup and diagnostics, expands playlist-probe coverage,
and completes the cross-platform Chrome browser companion packaging path.

## Highlights

- Refined the Active Downloads empty state and required-tools setup dialog with
  clearer hierarchy, spacing, action targets, contrast, and narrow-window
  readability.
- Standardized worker diagnostics and split yt-dlp process, metadata, output,
  download-row progress, and main-window download wiring into focused source
  units.
- Added a real slow-probe regression test covering ordinary-URL fallback and
  explicit-playlist failure classification.
- Packaged and registered the native browser-messaging host on Linux and macOS,
  including a persistent AppImage wrapper for Linux registrations.
- Improved POSIX worker/helper process termination and internal Qt path
  normalization.
