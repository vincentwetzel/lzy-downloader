# LzyDownloader 1.2.60

**More reliable sign-in recovery:** Downloads that require authentication now
recognize yt-dlp's “Log in for access” diagnostic and retry once with the
configured browser cookies.

The bundled yt-dlp and gallery-dl extractor catalogs are refreshed for this
release.
