# LzyDownloader v1.2.51

This release makes application updates safer when clipboard automation or
startup binary setup is active, and refreshes the extractor catalogs.

- Defer clipboard auto-paste/enqueue activity while an application update check,
  prompt, or installer handoff is active.
- Reject new GUI and non-interactive download admission during installer
  shutdown, with observable feedback for automation callers.
- Replay the latest deferred clipboard action when an update is cancelled or
  otherwise does not install.
- Refresh the yt-dlp and gallery-dl extractor catalogs.

Release assets:

- Windows installer: `LzyDownloader-Setup-1.2.51.exe`
- Linux AppImage: `LzyDownloader-1.2.51-x86_64.AppImage`
- Intel macOS DMG: `LzyDownloader-1.2.51-macos-x86_64.dmg`
- Apple Silicon DMG: `LzyDownloader-1.2.51-macos-arm64.dmg`
