# LzyDownloader v1.2.39

This release streamlines external-tool setup and upgrades into one focused
checklist.

- Consolidates missing-tool and outdated-binary prompts into **Set Up Required Tools**.
- Shows the recommended package-manager or app-managed install method inline.
- Updates detected binaries in their existing locations instead of creating duplicate app-managed copies.
- Adds one-click **Update All** handling for supported installs and upgrades.
- Improves checklist spacing, contrast, status hierarchy, and recovery actions.
