# LzyDownloader 1.2.54

This release hardens startup recovery and refreshes downloader support catalogs.

- **Coordinator startup:** Probe for an existing local coordinator before
  binding an endpoint, then recover stale endpoints only after a fresh listen
  fails. This reduces duplicate-owner races across GUI, server, and headless
  launches.
- **Aria2c fallback diagnostics:** Retry once with yt-dlp's native downloader
  for the Windows unreachable-network diagnostic while keeping unrelated code
  1 failures terminal.
- **Headless validation:** Improve direct QtTest diagnostics across Windows
  and WSL/Linux, with serial focused and full-suite runs.
- **Extractor catalogs:** Refresh the bundled yt-dlp and gallery-dl catalogs.
