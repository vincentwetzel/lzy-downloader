# LzyDownloader v1.2.35

This maintenance release fixes the GitHub Actions release workflow so all
platform artifacts can complete after the v1.2.34 CI optimization.

## Highlights

- Restores Python 3.11 after Qt setup so `yt-dlp` and `gallery-dl` are visible
  to the extractor refresh scripts.
- Removes the incompatible filtered Linux Qt archive request for Qt 6.10.2.

## Assets

- Windows installer: `LzyDownloader-Setup-1.2.35.exe`
- Linux AppImage: `LzyDownloader-1.2.35-x86_64.AppImage`
- Intel macOS DMG: `LzyDownloader-1.2.35-macos-x86_64.dmg`
- Apple Silicon macOS DMG: `LzyDownloader-1.2.35-macos-arm64.dmg`
