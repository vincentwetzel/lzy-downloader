# LzyDownloader v1.2.37

This maintenance release fixes Linux AppImage packaging and adds safe CI build
caching.

## Highlights

- Packages the SQLite driver without scanning unused Qt SQL drivers that require
  unavailable external database libraries.
- Enables Qt SDK caching, Linux compiler caching, and Ninja for faster repeat
  releases.

## Assets

- Windows installer: `LzyDownloader-Setup-1.2.37.exe`
- Linux AppImage: `LzyDownloader-1.2.37-x86_64.AppImage`
- Intel macOS DMG: `LzyDownloader-1.2.37-macos-x86_64.dmg`
- Apple Silicon macOS DMG: `LzyDownloader-1.2.37-macos-arm64.dmg`
