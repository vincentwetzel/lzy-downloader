# LzyDownloader v1.2.49

This release hardens runtime coordination, non-interactive queue feedback,
Windows packaging validation, and sleep prevention during active downloads.

- Prevent older GUI/server instances from launching a second queue owner during
  upgrades, avoiding Local API conflicts and duplicate-process hangs.
- Report asynchronous metadata-validation rejections to non-interactive callers
  through a terminal failure webhook instead of leaving requests orphaned.
- Fail Windows release packaging early when a MinGW executable is missing a
  required runtime DLL beside the application.
- Keep Windows systems awake during active downloads and post-processing without
  forcing the display to remain on.
- Refresh the yt-dlp extractor catalog for the release.

Release assets:

- Windows installer: `LzyDownloader-Setup-1.2.49.exe`
- Linux AppImage: `LzyDownloader-1.2.49-x86_64.AppImage`
- Intel macOS DMG: `LzyDownloader-1.2.49-macos-x86_64.dmg`
- Apple Silicon DMG: `LzyDownloader-1.2.49-macos-arm64.dmg`
