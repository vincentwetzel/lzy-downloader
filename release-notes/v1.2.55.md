# LzyDownloader 1.2.55

Share links directly from text: LzyDownloader now extracts HTTP(S) URLs from
pasted text and Markdown links in both desktop and Local API requests. This
release also refreshes the bundled yt-dlp and gallery-dl extractor catalogs.
