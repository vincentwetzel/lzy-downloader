# LzyDownloader v1.2.31

This release strengthens download recovery, diagnostics, testing, and release
maintenance.

## Highlights

- Added normalized media identity checks across queued, active, paused, retry,
  and archived downloads to prevent equivalent duplicates.
- Added safe explicit re-download recovery for stopped/failed jobs while
  preserving genuinely paused downloads.
- Hardened retry and resume handling against concurrent queue changes.
- Added terminal disk-space and incomplete-media diagnostics, including
  bounded aria2c-to-native-yt-dlp recovery while preserving partial files.
- Improved native progress recovery when yt-dlp omits stream sizes or becomes
  temporarily quiet.
- Added cross-platform idle-sleep inhibition for GUI and headless/server
  downloads without forcing the display to remain on.
- Added authenticated Local API cancellation and terminal diagnostics for
  rejected non-interactive requests.
- Expanded Qt regression coverage for queue persistence, duplicate recovery,
  temporary cleanup, destination replacement, playlist fallback, and aria2c
  recovery boundaries.
- Improved release safety by requiring release versions to advance beyond the
  latest tag and requiring tag/version agreement in tag-triggered CI.
